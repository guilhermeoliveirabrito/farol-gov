# Segurança

## Reportando uma vulnerabilidade no farol-gov

Se você encontrou uma falha no código ou na página do farol-gov, por favor **não abra uma issue pública**. Use o [reporte privado de vulnerabilidades do GitHub](https://github.com/guilhermeoliveirabrito/farol-gov/security/advisories/new).

Respondo em até 7 dias e aviso quando a correção for publicada. Se quiser, seu nome entra nos créditos.

## Falhas nos sites avaliados

O farol-gov **não** recebe nem repassa vulnerabilidades dos sites das prefeituras. Se você encontrou uma falha em algum deles, procure o `security.txt` do próprio site ou o [CERT.br](https://www.cert.br/), que é o canal nacional para notificação de incidentes.

## Escopo

- Código deste repositório (`farol/`, `scripts/`, `site/`)
- Workflows em `.github/workflows/`
- A página publicada em https://guilhermeoliveirabrito.github.io/farol-gov/
