              Como a nota é calculada

              Cada item vale uma quantidade de pontos. DMARC e HTTPS valem mais porque protegem o cidadão diretamente. Item cumprido conta inteiro e parcial conta metade. A nota vai de 0 a 100: A a partir de 90, B a partir de 75, C a partir de 55, D a partir de 35 e F abaixo disso. Detalhes na metodologia.
