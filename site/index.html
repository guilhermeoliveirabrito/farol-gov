O site da sua prefeitura protege você?

O farol-gov verifica se os sites e e-mails das prefeituras brasileiras seguem o básico de segurança: HTTPS de verdade, TLS atualizado, DNSSEC e proteção contra e-mails falsos. Só verificações passivas, as mesmas que um navegador faz.

    Como a nota é calculada

    Cada item vale uma quantidade de pontos (DMARC e HTTPS valem mais, porque afetam o cidadão diretamente). Item atendido vale 100%, parcial vale 50%. A nota vai de 0 a 100: A a partir de 90, B a partir de 75, C a partir de 55, D a partir de 35 e F abaixo disso. Metodologia completa.
